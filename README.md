# 우체국보험 공시실 약관 검색 아카이브

우체국보험 공시실(epostlife.go.kr) **상품공시 > 상품목록**에 올라온 상품 약관을 모아,
판매상태·보험종류·판매연도로 추리고 **약관 본문 키워드**로 찾을 수 있게 만든 정적 사이트입니다.

- 사이트: <https://dino790.github.io/epost-terms/>
- 본문 검색: <https://dino790.github.io/epost-terms/index.html>
- 목록 검색: <https://dino790.github.io/epost-terms/search.html>

## 수집 범위

| 구분 | 값 |
| --- | --- |
| 문서 항목(index.json 행) | 849건 (판매중 108 · 판매중지 741) |
| 약관 파일(txt) | 787개 / 약 140MB |
| 총 페이지 | 83,046쪽 |
| 추출 텍스트 | 약 6,403만 자 |
| 수집일 | 2026-11-24 (KST) · 스캔본 OCR 보완 2026-11-25 |

- 대상: 상품요약서·사업방법서는 제외하고 약관류(약관, 약관1~6)만 수집했습니다.
- 판매중 상품 중 45건은 공시실이 기초서류 파일경로를 반환하지 않아 원문을 확보하지 못했습니다(해당 행은 `pdf_url`이 비어 있고 화면에 "본문 미확보"로 표시됩니다).
- 처음에 스캔본이라 텍스트가 없던 6건(21001_1·21001_2·21001_3·5126·Health_3·anarmful_2)은 OCR(RapidOCR PP-OCRv5 korean, 300dpi)로 본문을 추출해 `txt/`와 `index.json`에 반영했습니다. 해당 행은 `note`에 "스캔본 OCR 추출"로 표시되며 OCR 특성상 원문과 글자 단위 오차가 있을 수 있습니다. 텍스트가 없는 문서는 현재 없습니다(`scanned_no_text: true` 0건).

## 파일 구성

```
index.html   본문 검색 웹앱 (필터 + 키워드 본문 검색)
index.json   문서 메타데이터 849행 (아래 필드)
search.html  단순 목록·메타 검색 (자체 데이터 내장)
txt/         약관별 페이지 텍스트 787개 (`--- PAGE N ---` 구분선)
```

`index.json` 각 행:

```json
{
  "status": "판매중", "category": "기타보험",
  "product_name": "…", "product_code": "P800027",
  "sales_period": "2025.04.03.~", "doc_label": "약관",
  "pdf_url": "https://www.epostlife.go.kr/…/YAK_P800027_202504.pdf",
  "filename": "YAK_P800027_202504.pdf",
  "pages": 241, "text_chars": 165187,
  "scanned_no_text": false, "note": "",
  "txt_file": "YAK_P800027_202504.txt", "txt_bytes": 331420,
  "y0": 2025, "y1": null
}
```

- `txt_file`은 `txt/` 안의 파일명입니다. 같은 파일을 여러 행이 공유할 수 있습니다(1종/2종, 기간 분할 등 → 849행 / 787파일).
- `text_chars`는 PDF 추출 텍스트를 줄바꿈·페이지 구분선 없이 센 글자 수입니다(스캔본 6건은 OCR 결과 기준).
- `y0`·`y1`은 판매기간의 시작·종료 연도입니다. `y1`이 `null`이면 판매중(기간 열림)입니다.
- PDF 원본(1.06GB)은 저장소에 포함하지 않았습니다. 원문은 `pdf_url`(공시실)에서 바로 열립니다.

## 본문 검색 동작

- 필터(판매상태·보험종류·판매연도·상품명/코드/파일명)로 대상을 좁힌 뒤 **선택/필터된 상품 본문 검색**을 누르면,
  해당 상품들의 `txt/` 파일을 동시 6개씩 `fetch()`로 받아 브라우저에서 검색합니다.
- 판매연도는 **기간이 겹치는 상품까지** 포함합니다(예: `2022` → `'21. 09. 01 ~ '25. 04. 30` 상품 포함).
- PDF 추출 텍스트는 줄바꿈으로 단어가 끊겨 있어, 검색은 **공백을 무시하고** 비교합니다(`제왕절개`, `제왕 절개`, `제왕절\n개` 모두 일치).
- 결과는 상품별 일치 건수·페이지 번호·앞뒤 문맥과 함께 보여 주고, 약관 전문/페이지 보기와 공시실 원문 PDF 링크를 제공합니다.
- 처음 검색은 내려받는 양이 많아 시간이 걸립니다(전체 787개 ≈ 140MB). 시작 전에 예상 용량을 보여 주고 확인을 받습니다.
